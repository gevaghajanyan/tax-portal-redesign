## Detailed description

Paste this into the "Description" field. Plain text — the Web Store does
not render Markdown, so I've used ASCII characters that still look good.

```
Make the Armenian State Revenue Committee's personal-account portal
usable on a modern browser — without changing how it works.

personal-account.taxservice.am is built on a 2009-era RichFaces/JSF
template with nested layout tables, tiny text, cramped forms, and a
look that doesn't scale well. This extension injects a clean, modern
redesign on top of it. Original form logic, AJAX submits, and
validation stay exactly as they are — only the appearance changes.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
WHAT IT COVERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Login page — centered card, modern inputs, clear primary button
• Personal info, change-password, feedback pages — card-based layout
• Income-tax-return list — proper table with modern search filters
• The income-tax-return application form — the full form reimagined
  as grouped sections instead of a wall of nested tables
• Debts, notifications, payments — the same clean treatment
• Modal panels (notifications, loader) — rounded cards with proper
  typography instead of 90s dialogs

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✓ One-click on/off switch — flip back to the original site any time
✓ 9 primary color presets (Blue, Indigo, Purple, Pink, Red, Orange,
  Green, Teal, Slate) applied live to header, sidebar, buttons,
  focus rings, modals, calendar
✓ Light / Dark / System appearance — dark mode re-skins page
  backgrounds, cards, tables, inputs, modals. "System" tracks your
  OS theme and flips automatically.
✓ Adjustable text size (90% / 100% / 110% / 125%) via A- / A / A+
  buttons in the popup
✓ Keyboard shortcut Alt+Shift+T to toggle the redesign without
  opening the popup (customizable at chrome://extensions/shortcuts)
✓ Localized popup — English and Armenian, matches your browser
  language automatically
✓ All settings persist across tabs and sessions

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
PRIVACY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• No data from the tax portal is collected, read, logged, or
  transmitted — not your SSN, tax ID, bank account, employer,
  income, tax amounts, or anything else
• No analytics, no telemetry, no tracking
• No network calls — the extension never contacts any server
• No remote code — all HTML/CSS/JS is bundled locally
• The only stored data is four UI preferences (on/off, color,
  theme, text size) kept locally via chrome.storage.local
• Content script runs only on personal-account.taxservice.am

Full privacy policy is published in the open-source repository.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HOW TO USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Install the extension
2. Open personal-account.taxservice.am
3. The redesign is on by default
4. Click the extension icon to toggle it off, pick a different
   primary color, switch to dark mode, or adjust text size

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• This is an unofficial extension — not affiliated with or endorsed
  by the Armenian State Revenue Committee
• Works on Chrome 100+ (and Chromium browsers: Edge, Brave, Opera,
  Arc, Vivaldi)
• Open source and audit-friendly — all source code is available
  and plain HTML/CSS/JS, no build step, no minification

Contact: gev.aghajanian@gmail.com
```
